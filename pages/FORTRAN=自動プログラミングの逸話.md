- 年は1957（Backusら "[[The FORTRAN Automatic Coding System]]" 1957-02発表、リリース1957-04。プロジェクト開始は1954、マニュアル "The Fortran Automatic Coding System for the IBM 704" は1956）
- 『[[コーディングを支える技術]]』(2013)には書いていない。原著第2章のFORTRANは「数式を機械語へ翻訳、人間が楽をするため」の文脈のみで、「自動プログラミング」の呼称の話は無い
- 活字での既出は『エンジニアの知的生産術』導入コラム「[[なぜ知的生産術に投資するのか]]」（技術評論社 電脳会議 vol.190、2018-10）
- さらに: langbook2026（コーディングを支える技術改訂プロジェクト）のchapter_planに「FORTRANは自動プログラミングと呼ばれていた→LLMコード生成との並行」が改訂で追加予定の項目として既にある。LTでこの接続を口頭で試すのは改訂のリハーサルにもなる
- ∴ LTでは書籍への帰属は言わない（「本に書いた」は不正確）。単に歴史の話として語る
