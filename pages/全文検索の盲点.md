増井さんの問題提起
- 全文検索は便利だが足りないところが多い
    - 見つかった情報の周辺情報が分からない
    - 用語が微妙に違うと見つからない
- どちらもリンクで解決できるので、リンクの多い情報を全文検索するのが正しい。これを説得力のある形で言えるか
shokai さん
- 「リンク構造だけで見つかるの？」と聞かれたら「全文検索で近そうなページを見つければ、そこから最悪でも 2、3 クリックで着く」と答えると納得される（[[道のメタファー]]）
- 検索結果が謎のスコアで並び、順番に納得がいかない
- java を探すと javascript ばかり出る。javascript を除外すると両方に触れたページも消える
- リンク構造のない文書群を全文検索するのは Google 以前に戻るのと同じ。[[pagerank]] はリンク構造からスコアを出すもの
rakusai さん
- 一番の問題は並び順
- 組織内の情報を [[tf-idf]] や日付順で並べても、欲しい情報に 1 ページ目で届かない。既存ページが更新されず、似たページが重複して作られ、ゴミの山になる
- ページビュー順は上位に閲覧が集まるので機能しない。「いいね」順もいまいち
