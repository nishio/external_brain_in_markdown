- David Allen の [[GTD]] にある、やることを高さの段に分けて見る考え方です。Allen 自身は飛行機の高度にたとえています。
:
| 高さ | 中身 |
| -- | -- |
| 50,000 フィート | [[人生の目的]]、[[価値観]] |
| 40,000 | 3〜5 年の構想 |
| 30,000 | 1〜2 年の目標 |
| 20,000 | 責任を持つ領域 |
| 10,000 | プロジェクト |
| 滑走路 | 次にやる具体的な行動 |

下ほど数が多く、上ほど少ないので、絵にすると三角形になります。
『[[エンジニアの知的生産術]]』の 2 章は人生の目標を「[[ピラミッドの頂上部分]]」と書いています。

下から登る: まず Inbox に全部出して片付け、似たものを束ねて「これは何のためか」と考えて上の段を見つける。
- GTD は下から登るほうを勧めています。頭の中が目の前のことで埋まっているうちは、上の段を考える余裕が無いからです。
- 西尾さんの [[GTDとKJ法のアナロジーの言語化]]（2014 年）は、この登る動きが KJ 法のグループ編成と同じだと書いています。
